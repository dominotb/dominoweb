# Design System 	6 DOMINO Glass Kitchen

Generated from the `ui-ux-pro-max` skill search for the project "DOMINO Glass Kitchen".

## Pattern
- Name: Hero + Features + CTA
- Conversion Focus: Deep CTA placement. For CTA label text, verify at least 4.5:1 against the button fill; use 7:1 only when the product explicitly targets AAA normal-text contrast. Keep focus and component boundaries independently visible. Disable hero parallax under reduced motion and render its static final state.
- CTA Placement: Hero (sticky) + Bottom
- Color Strategy: Hero: Brand primary or vibrant. Features: Card bg #FAFAFA. CTA: Contrasting accent color
- Sections: Hero with headline/image > Value prop > Key features (3-5) > CTA section > Footer

## Style
- Name: Minimalism & Swiss Style
- Mode Support: Light supported | Dark supported
- Keywords: Clean, simple, spacious, functional, white space, high contrast, geometric, sans-serif, grid-based, essential
- Best For: Enterprise apps, documentation, product marketing and high-trust brand sites
- Performance: cost:low | Accessibility: risk:low | Requires: contrast-text-4.5, keyboard, visible-focus, reduced-motion

## Typography
- Primary font: Inter (retain for all UI text)
- Recommended weights: 300, 400, 500, 600
- Google Fonts import:
```css
@import url('https://fonts.googleapis.com/css2?family=Inter:wght@300;400;500;600&display=swap');
```

Guidance: Use Inter for headings and body. Limit display headline scale per page to a single dominant headline; avoid oversized decorative headings that cause clip/overflow in Vietnamese.

## Layout & Grid
- Desktop: 12-column grid
- Tablet: 8-column grid
- Mobile: 4-column grid
- Spacing rhythm: 8px base (scale: 8 / 16 / 24 / 32 / 48 / 64)

## Hero
- Large full-bleed image, controlled overlay for legibility. Headline: "TỦ BẾP CHO NHỮNG NĂM THÁNG PHÍA TRƯỚC." Use a concise 1-line description and a single primary CTA `Khám phá`.

## Product Range
- Four families: Basic, Signature, Premium, VIP. Display family card with image, short positioning line, and link to detail. Do not show prices on public pages.

## Warranty
- Represent warranty per family via `warranty_policies` CMS reference. Do not generalize maximum values across families.

## Images
- Prioritize DOMINO-owned photography. Fall back to labeled demo images only in preview environments. Include `focal_point` metadata per image to avoid awkward crops.

## Motion
- Motion tone: slow, controlled, purposeful. Typical durations: 180220ms (fast), 300400ms (standard), 600800ms (long). Respect `prefers-reduced-motion`.

## Accessibility
- Text contrast: 4.5:1 for body; 3:1 only for large display text.
- Keyboard focus styles present for interactive elements.
- Decorative icons `aria-hidden="true"`; meaningful icons expose accessible names.

## Pre-Delivery Checklist
- No emojis as icons; use SVG vector icons (Phosphor / Heroicons)
- Inter font included and applied site-wide
- All CTAs pass contrast checks
- Focus states visible and keyboard-navigable
- Responsive breakpoints verified: 375px, 768px, 1024px, 1440px

## Implementation Notes
- Homepage should be a Server Component (Next.js App Router recommended) that pulls data from `product_lines`, `warranty_policies`, `projects`, `posts`, and `media` tables in Supabase.
- Do not embed Supabase service keys in client bundles. Use environment-driven server-side calls and RLS.
